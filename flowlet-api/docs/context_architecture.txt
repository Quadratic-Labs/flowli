Context Management Architecture for Flowlet
===========================================

┌─────────────────────────────────────────────────────────────────────────┐
│                        THREAD ISOLATION                                  │
│                                                                           │
│  Thread 1                          Thread 2                              │
│  ┌──────────────────┐             ┌──────────────────┐                  │
│  │ Flow "checkout"  │             │ Flow "analytics" │                  │
│  │ run_id: aaa-111  │             │ run_id: bbb-222  │                  │
│  └────────┬─────────┘             └────────┬─────────┘                  │
│           │                                 │                             │
│           │ ContextVar stores:              │ ContextVar stores:          │
│           │ flow_run_id = "aaa-111"         │ flow_run_id = "bbb-222"     │
│           │                                 │                             │
│           ├─► Task: validate_cart           ├─► Task: compute_metrics    │
│           │   Gets: "aaa-111" ✓             │   Gets: "bbb-222" ✓         │
│           │                                 │                             │
│           ├─► Task: process_payment         ├─► Task: aggregate_data     │
│           │   Gets: "aaa-111" ✓             │   Gets: "bbb-222" ✓         │
│           │                                 │                             │
│           └─► Task: send_confirmation       └─► Task: generate_report    │
│               Gets: "aaa-111" ✓                 Gets: "bbb-222" ✓         │
│                                                                           │
│  ✅ NO INTERFERENCE - Each thread has isolated context                   │
└─────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────┐
│                      ASYNC TASK ISOLATION                                │
│                                                                           │
│  async Task 1                      async Task 2                          │
│  ┌──────────────────┐             ┌──────────────────┐                  │
│  │ Flow "import"    │             │ Flow "export"    │                  │
│  │ run_id: ccc-333  │             │ run_id: ddd-444  │                  │
│  └────────┬─────────┘             └────────┬─────────┘                  │
│           │                                 │                             │
│           │ await fetch_data()              │ await load_data()           │
│           │ Context preserved! ✓            │ Context preserved! ✓        │
│           │                                 │                             │
│           ├─► await validate()              ├─► await transform()        │
│           │   Gets: "ccc-333" ✓             │   Gets: "ddd-444" ✓         │
│           │                                 │                             │
│           └─► await store()                 └─► await upload()           │
│               Gets: "ccc-333" ✓                 Gets: "ddd-444" ✓         │
│                                                                           │
│  ✅ CONTEXT PRESERVED across await boundaries                            │
└─────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────┐
│                   CONTEXT LIFECYCLE MANAGEMENT                           │
│                                                                           │
│  1. Flow Starts                                                          │
│     ┌────────────────────────────────────┐                              │
│     │ with FlowContext("my_flow"):       │                              │
│     │   # __enter__ called:               │                              │
│     └────┬───────────────────────────────┘                              │
│          │                                                                │
│          ├─► Create DB record (FlowRun)                                  │
│          │   flow_run_id = uuid4()                                       │
│          │                                                                │
│          ├─► Set contextvar                                              │
│          │   token = current_flow_run_id.set(flow_run_id)               │
│          │                                                                │
│  2. Tasks Execute                                                        │
│          │                                                                │
│          ├─► task1() calls current_flow_run_id.get()                    │
│          │   → Returns flow_run_id ✓                                     │
│          │                                                                │
│          ├─► task2() calls current_flow_run_id.get()                    │
│          │   → Returns flow_run_id ✓                                     │
│          │                                                                │
│  3. Flow Ends                                                            │
│     ┌────┴───────────────────────────────┐                              │
│     │   # __exit__ called:                │                              │
│     │   # Update DB record                │                              │
│     │   # ALWAYS reset context:           │                              │
│     │   current_flow_run_id.reset(token)  │                              │
│     └─────────────────────────────────────┘                              │
│                                                                           │
│  ✅ Automatic cleanup with context managers                              │
└─────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────┐
│              CONTEXTVAR vs GLOBAL VARIABLE COMPARISON                    │
│                                                                           │
│  Using Global Variable (NOT SAFE):                                       │
│  ───────────────────────────────────                                     │
│                                                                           │
│    global_flow_id = None  ← Shared across all threads!                  │
│                                                                           │
│    Thread 1                    Thread 2                                  │
│    ┌─────────┐               ┌─────────┐                                │
│    │ Set to  │               │ Set to  │                                │
│    │ "aaa"   │  ────────────▶│ "bbb"   │                                │
│    └────┬────┘               └─────────┘                                │
│         │                                                                 │
│         └─► Read value                                                   │
│             Got: "bbb" ✗  (WRONG! Race condition!)                      │
│                                                                           │
│  ──────────────────────────────────────────────────────────────────────│
│                                                                           │
│  Using ContextVar (SAFE):                                                │
│  ─────────────────────────                                               │
│                                                                           │
│    current_flow_id = ContextVar(...)  ← Isolated per thread!            │
│                                                                           │
│    Thread 1                    Thread 2                                  │
│    ┌─────────┐               ┌─────────┐                                │
│    │ Set to  │               │ Set to  │                                │
│    │ "aaa"   │               │ "bbb"   │                                │
│    └────┬────┘               └────┬────┘                                │
│         │                          │                                     │
│         └─► Read value             └─► Read value                       │
│             Got: "aaa" ✓               Got: "bbb" ✓                     │
│             (CORRECT!)                  (CORRECT!)                       │
│                                                                           │
└─────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────┐
│                      CODE PATTERN SUMMARY                                │
│                                                                           │
│  Define Once:                                                            │
│  ────────────                                                            │
│    # executors/context.py                                                │
│    current_flow_run_id = ContextVar('flow_run_id', default=None)        │
│    current_task_run_id = ContextVar('task_run_id', default=None)        │
│                                                                           │
│  Use in Flow Runner:                                                     │
│  ────────────────────                                                    │
│    class FlowContext:                                                    │
│        def __enter__(self):                                              │
│            self._token = current_flow_run_id.set(self.flow_run_id)      │
│            return self                                                   │
│                                                                           │
│        def __exit__(self, exc_type, exc_val, exc_tb):                   │
│            current_flow_run_id.reset(self._token)  # ALWAYS!            │
│                                                                           │
│  Use in Task Executor:                                                   │
│  ──────────────────────                                                  │
│    class TaskExecutor:                                                   │
│        def execute(self, task_fn, *args, **kwargs):                     │
│            flow_run_id = current_flow_run_id.get()  # No params!        │
│            if flow_run_id is None:                                       │
│                raise RuntimeError("No active flow")                      │
│            # ... track task execution ...                                │
│                                                                           │
│  Client Code (Clean!):                                                   │
│  ──────────────────────                                                  │
│    @flow                                                                 │
│    def my_flow():                                                        │
│        task1()  # No flow_run_id parameter needed!                      │
│        task2()  # Context propagates automatically!                     │
│                                                                           │
└─────────────────────────────────────────────────────────────────────────┘


KEY PRINCIPLES:
===============
✅ Use ContextVars for implicit context propagation
✅ Always store tokens and reset in finally blocks
✅ Use context managers (with statements) for lifecycle
✅ Don't mix explicit passing with contextvars
✅ Test with multiple threads to verify isolation
